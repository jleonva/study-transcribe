# Local PDF transcription evaluation: MM-Agent paper

Date: 2026-10-17

Target: [`study-transcribe`](https://github.com/jleonva/study-transcribe)

Paper: Liu et al., *MM-Agent: LLM as Agents for Real-world Mathematical Modeling Problem*, arXiv:2505.14148v1, 47 pages. The paper is licensed CC BY-NC-ND 4.0. This public report intentionally contains no paper text, formulas, PDF, or full transcript.

## Scope and privacy

The PDF was processed locally. No hosted inference or transcription API was called. The public artifacts retain only aggregate counts, tool versions, and resource links. The PDF, extracted Markdown, equation excerpts, and MinerU output remain outside this repository.

## Baseline run

The repository's current `scripts/run.py` pipeline (PyMuPDF4LLM and pix2tex) processed pages 1–47 in 167.0 seconds on the local Windows/Python 3.11.5 environment.

| Measure | Result |
| --- | ---: |
| Pages classified as native-text | 47 / 47 |
| Image formula candidates | 4 |
| Formula candidates recognized as LaTeX | 0 / 4 |
| Formula candidates that were actually equations | 0 / 4 |
| Remaining image references for manual review | 10 |
| Display-math blocks recovered in Markdown | 0 |

This is a poor result for equation transcription. The input has a selectable text layer, so most prose was recovered, but mathematical notation was flattened or misordered in places; vector/display equations were not captured by the image-crop OCR route. The four candidate crops were inspected and were logos/diagrams/caption-like content rather than equations. Some repeated fragments of real document content were also removed by the old global repeated-line cleanup; the cleanup was changed to remove standalone page-number lines only.

The 0/4 result is exact for the four image candidates emitted by this run, not a recall estimate over every equation in the paper. The paper's HTML source was used as a reference to confirm that the paper contains equations; equation-by-equation recall is therefore unscored. A reliable formula-region ground-truth annotation was not built.

## Local alternative checked

[MinerU](https://github.com/opendatalab/MinerU) 4.0.12 was installed in an isolated temporary environment. The verified ONNX basic bundle occupied 858,210,308 bytes (~819 MiB), below the 1.5 GB model cap. The batch CLI was invoked with `--tier basic`, local model source, and no remote option, first on the whole PDF and then on one page. Both invocations stalled without producing output; neither can be scored. The full alternative was not integrated because it did not pass a local inference smoke check, and its current project license is separately worded from the repository's MIT license.

Other open local candidates:

- [Nougat](https://github.com/facebookresearch/nougat) is a whole-document scientific PDF-to-Markdown/LaTeX model. It is a stronger architectural match for paper-level math than crop-only OCR, but its weights and Windows/CPU setup were not evaluated in this run.
- [UniMERNet](https://github.com/opendatalab/UniMERNet) is an equation-image recognizer with reported tiny/small/base weights around 441/773/1,300 MB. It needs formula-region detection first, so it does not address this run's false-positive crop detector on its own.
- MinerU's basic ONNX model package includes formula-related components and is the most promising lightweight local all-in-one candidate found, but requires a separate successful runtime check before adoption.

These are candidate resources, not measured accuracy claims. This repository keeps the existing pix2tex implementation, adds no unverified backend, and now preserves repeated text conservatively.

## Reproduction

The baseline was run with the existing repository virtual environment against local file `MM-Agent-arxiv-2505.14148.pdf`, pages `1-47`. That source PDF is intentionally not included here. The paper's public landing page and HTML are available at <https://arxiv.org/abs/2505.14148> and <https://arxiv.org/html/2505.14148>.

The model-free checks for this code change are:

```powershell
.\.venv\Scripts\python.exe tests\cleanup_regression.py
.\.venv\Scripts\python.exe tests\smoke.py
```
